📌 Критические правила
Не вводить несколько новых средств одновременно — реакцию не атрибутировать
SPF — ежедневно, включая пасмурные дни и нахождение у окна
Не перегружать слоями: каждый слой — обоснование, не привычка
Контроль реакции кожи: 7 дней наблюдения после введения нового средства
Витамин C — только на сухую кожу, иначе нестабильность формулы
Азелаиновая — строго перед кремом, не после
Осенью — план введения ретиноидов. Без них anti-age работает на уровне поддержки, не коррекции
⏱ Ожидания по срокам
2–4 недели: выравнивание тона, первые признаки сияния от витамина C
6–8 недель: уменьшение воспалений, стабилизация барьера
8–12 недель: заметное улучшение текстуры при добавлении ниацинамида / пептидов
Морщины и птоз — без ретиноидов не адресуются. Честный прогноз
🧠 Ключевое
Защита → антиоксиданты → контроль воспаления → минимальные слои. Реакция кожи важнее отзывов. Азелаиновая — союзник, но не основа anti-age при 55+.
⛔ Стоп-флаги — убрать средство
🔥 Жжение дольше 10–15 минут
🔴 Устойчивое покраснение (держится >30 мин)
🍂 Шелушение в сочетании с зудом
⚪ Появление закрытых комедонов
💧 Резкое усиление сухости или стянутости
❌ При любом флаге — убрать последнее введённое средство. Не несколько сразу
⚠️ Провал-сценарии по средствам
Витамин C + влажная кожа → оксидация, жжение. Решение: наносить только на сухую
SPF скатывается → крем нанесён слишком толстым слоем. Решение: горошина крема, дать впитаться 2 мин
Азелаиновая после крема → барьер блокирует проникновение. Эффект нулевой
Тонер в избытке → липкость, нарушение нанесения следующего слоя. 2–3 капли максимум
Несколько новых средств одновременно → при реакции невозможно определить виновника
🔄 Что делать если…
Кожа покраснела после C10 → пауза 3 дня, затем через день, потом ежедневно
SPF даёт белый каст → UVMune 400 бесцветный, проверить количество — 2 пальца обязательно
Кожа стянута после очищения → CeraVe заменить на более липидный вариант (CeraVe Cream-to-Foam или Avène Toleriane)
Азелаиновая не даёт результата за 6 недель → увеличить частоту до ежедневной при отсутствии реакции
